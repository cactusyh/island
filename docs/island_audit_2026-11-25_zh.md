# ISLAND 严格审查与开发建议（2026-11-25）

审查基线：`2bfd33f`，J105。目标是从 PSMILES 和必要配方信息构建多种链与网络，分配指定的 PCFF、GAFF/GAFF2 或 OPLS，再运行分子动力学。

**结论：ISLAND 已有真实可执行、保留来源与检查点的研究原型，但尚未成为广泛化学覆盖的通用聚合物模拟平台。当前最高优先级是统一并修正“最终化学图”的构建与分配路径，然后扩大经过验证的化学环境及交联反应覆盖。** 现有的参数分配成功率、完整配方成功率和材料性质可靠性必须分别评价。

## 1. 本次做了什么

- 阅读构建器、最终图规范化器、两套参数后端、recipe、周期固化、分型扩展和 MD/分析接口的关键代码，并核对 J94–J105 的相关证据。本次不是对全部历史模块的穷尽审计。
- 实际复跑关键接口测试 42 项，构建器、立体化学与 J101/J102 相关测试 62 项，**共 104 项通过**。这不包含整个仓库测试套件。
- 新做 14 个化学输入 × 2 套力场 × 2 种入口的 **56 次真实参数分配探针**；另检查手性、双键构型和端基行为。
- 校验 J104 证据指纹、J105 的主要证据文件和归档内 **2,514 个文件**。本次未重新执行全部 54 个 J105 MD 配方。
- 直接读取 RadonPy、PolyJarvis、polyply 的论文以及其他项目的官方文档/源码说明。外部软件没有在本次审查中做统一硬件、同体系的性能复测；其物性和规模结果属于作者报告。

运行环境中的 RDKit 为 `2026.03.6`。复现脚本、输入、成功和失败诊断、测试日志及来源指纹见 [审查证据](evidence/audit_20261125/manifest.json)。工作区已有的 J93 未提交改动不属于本次验证基线，本次未修改生产代码。

|---|---|---|

| PCFF 扩展 | `pcff-carboxamide-v1` 在 982 条重复单元面板为 899/982；严格立体化学口径 865/982 | 任意端基、嵌段接点和交联产物都完整；不同 PCFF 参数发行库可互换 |
| OPLS 扩展 | `opls-polymer-v1` 同面板为 406/982；严格口径 398/982；固定原始库为 270/982 | 406/982 就是当前完整图入口的覆盖率；新增成功结构的所有类型都已被独立参考逐原子验证 |
| 有限链配方 | J105：6 类化学 × 3 架构 × 3 力场，54/54 完成；每例 4 条 DP6 链、单种子、6.5 ps | 长链、高分散度、任意支链及组成、充分平衡的熔体 |
| 周期交联 | DGEBA/PACM 的 PCFF 与特定 OPLS profile；DGEBA/PETMP 的 PCFF；有周期贯穿统计和逐批续算 | 任意交联剂、反应化学及网络；GAFF 交联 recipe |
| 材料性质 | 已有密度、Tg、模量分析与尺寸/速率探索；J101 如实保留失败和未收敛结果 | 已建立大多数材料的可靠物性预测能力 |

J105 六类化学主要只含 C/H/O/N。更早的硫醇交联扩展了含硫案例，但不能用 J105 的 54/54 代表含氟、含磷、硅氧烷或带电聚合物。

“PolyJarvis 公开成功组合 611/611”属于一个固定版本的成功样本复现，其中混合了多种库和 AA/UA 模型。它不是 611 个 OPLS-AA 聚合物，更不是对其所有可能输入或后续版本的全面能力证明。[既有基准定义](reference_assignment_zh.md)

## 3. 需要优先处理的具体问题

### P1-A：默认封端会使部分有效手性 PSMILES 生成非预期自由基

输入 `*C[C@H](C)*`、DP3，通过 `PolymerRecipe → normalize → _build_chain` 时，图中出现一个自由基位点，随后报 `Supply a terminated, closed-shell molecular graph`。同一个输入走 GAFF2 的直接重复单元分配接口成功。

原因路径可定位到 [重原子拼接](../src/island/builders/polymer.py)：复制括号原子并去掉连接星号之后，默认端基依赖自动补氢；`[C@H]` 的显式氢计数和禁止隐式补氢状态使末端不等同于真正添加氢封端。直接 GAFF 路径则构造显式 `*[H]` 端基，并使用另一个立体化学重建器。[两种入口](../src/island/forcefields/assignment.py)

本次在 recipe 显式提供 `end_groups: ["*[H]", "*[H]"]` 后，该 PP 图可以成功构建。这既给出暂时可用的避让方法，也证明问题不在 GAFF 缺参数。另一个明确指定 isotactic 的 PP 测试仍遇到末端无法实现指定 R 构型的错误；需要处理封端后消失的立体中心，不能把默认氢封端修复当作 tacticity 已全部解决。

**验收要求：**默认与显式氢封端的最终图一致；合理的端基替换不产生非预期自由基；内部构型保留，末端失去手性时给出正确语义；覆盖 DP1、DP2、较长链和嵌段接点。[实际探针](evidence/audit_20261125/graph-probes.json) · [端基复验](evidence/audit_20261125/caps-probes.json)

### P1-B：E/Z 与多条建图路径尚未统一

`*C/C=C\C*` 在直接 GAFF2 分配入口成功并保留 E/Z，而 recipe 的规范化器明确添加 `double_bond_stereochemistry_requires_lossless_builder_adapter` 阻止项。这个阻止行为避免了静默丢失构型，是正确的保守处理；但它意味着“一份 PSMILES 能分配 GAFF”仍不足以保证完整模拟流程可运行。

[规范化器](../src/island/forcefields/assignment_core/topology.py) 与 [直接入口的立体化学处理](../src/island/forcefields/_repeat_stereo.py) 应使用统一的最终图规范：原子身份、显式氢、形式电荷、同位素、键序、E/Z、四面体构型、端基及连接映射。先验证图，再决定坐标和力场后端。

### P1-C：相同化学输入，OPLS 两个公开入口给出不同覆盖结论

本次使用同一 `opls-polymer-v1`、DP3 和氢封端，得到：

| 输入 | 重复单元入口 | 先建完整有限链，再分配 |
|---|---|---|
| PEG | 失败 | 成功 |
| PA6 | 失败 | 成功 |
| PET | 失败 | 成功 |
| 脂肪族聚氨酯测试单元 | 失败 | 成功 |
| PAN | 失败 | 失败：部分电荷与形式电荷不一致 |
| PVC | 失败 | 失败：`c4/cl1` 电荷增量缺失 |
| PEEK | 失败 | 失败：芳香/羰基相关扭转缺失 |

完整输入和原始诊断见 [56 次分配探针](evidence/audit_20261125/assignment-challenge.jsonl.gz)。这批是刻意挑选的挑战输入，不是随机抽样覆盖率。

代码把字符串输入送给 EMC 重复单元拼链，把完整图送给另一套图导出路径。因此，**应先以完整化学图重新测量统一入口的覆盖率，再决定有多少缺项需要增加参数。** 不能把所有旧入口失败都归为原子类型或参数库不足，也不能把这四个成功例子外推到全部 982 条输入。

当前 recipe 还先 PACKMOL 装填、再参数分配。对于已知缺参数的 PEEK/OPLS 等输入，这会先花费构象与装填成本。建议先对最终单链及所有不同接点执行参数预检，分配完整后再装填；缓存必须绑定图、端基、库指纹和电荷模型。

### P1-D：通用周期网络与 GAFF 网络参数化仍未打通

recipe 的 `crosslinked` 分支明确限制为 PCFF 和 2024 OPLS-AA；PETMP 进一步限制为 PCFF。组分及反应仍围绕 DGEBA、PACM、PETMP，不能仅传入任意 PSMILES/交联剂就执行相同固化流程。[配置限制](../src/island/workflows/recipe_config.py) · [反应模板](../src/island/epoxy/chemistry.py)

普通完整图适配器需要把每个分子有限展开，遇到绕盒共价环会拒绝。当前环氧路线用已验证的局部环境参数库绕过这个限制，这项工作有价值，但它是特定反应域的解决方案。[有限展开限制](../src/island/forcefields/_emc_graph_input.py) · [网络局部分配](../src/island/epoxy/parameters.py)

**建议：**引入通用反应定义与周期图接口，明确反应物、产物、原子映射、断键/成键、氢或离去基团处理、官能度、产物电荷及受影响的全部成键项。首先将一种现有环氧反应接入 GAFF/GAFF2，再支持用户提供不同单体实例和第二类反应。固定拓扑力场下的几何固化算法不能自动给出真实化学反应速率。

### P1-E：结构与端基的科学语义必须显式化

一个双连接点 PSMILES 描述重复单元，不唯一决定聚合物。它不能独自确定嵌段顺序、支化点、分子量分布、交联配比、反应机制、质子化态、反离子或模拟状态。

当前已有均聚、交替、嵌段、指定序列以及固定组成后打乱的随机共聚构建器。不能把这些已有功能误说成不存在。但公共 recipe 还没有把组分分布、逐链随机序列、独立链构象、混合物和分子量分布统一起来。支链通过主链既有位点编号和单连接点片段描述；复杂星形、梳形或树枝形结构可以部分手工编码，但缺少完整、经过验证的高层架构生成接口。

本次 PA6 默认氢封端生成 `N…C=O`，末端是醛而非羧酸。它是指定封端规则的结果，不应被误标成所有实验 PA6 的代表结构。对 PDMS，默认封端也出现闭壳层问题；使用明确的三甲基硅端基后，**本次 EMC PCFF 完整图分配成功，当前 OPLS profile 仍缺规则**。这不是 PDMS 物性验证，也不推翻其他 PCFF 发行库的历史缺项；它再次说明端基和具体库版本的重要性。

仓库另外存在外部 PDMS 研究模型和短程 NVT 证据，应作为独立模型展示，不能算成通用原生 OPLS-AA 已覆盖。[PDMS 研究接口边界](pdms_user_workflow.md)

### P2-A：长链构象、压实和平衡没有形成统一生产协议

J105 的构象重试确实恢复了 12 个装填失败案例，证据有效。但有限链仍先生成一个构象，再由 PACKMOL 放置相同构象的刚体副本。DP6、4 条链、单种子不足以覆盖长链缠结、密集支化、相分离或大网络。

当前 recipe 固定经过 NVT、NPT、production 三段。完成检查验证步数、轨迹、有限数值和 restart；`equilibrated` 明确写为 `unmeasured`。[MD 运行器](../src/island/workflows/recipe_md.py) 仓库已有 [平衡诊断模块](../src/island/analysis/equilibration.py)，但没有接成这一入口的自动续跑与生产段准入条件。

应加入独立链构象、分段生长或粗粒化回映射选项、受控压实/退火，以及密度和能量漂移、有效样本量、链尺寸、内距、取向与空间均匀性的联合诊断。具体时长应由体系和收敛指标决定，不能用一个统一短时长保证所有聚合物平衡。J101 中密度随观察窗口显著变化和部分速率拟合失败，是现成的反例与回归样品。

### P2-B：电荷模型、独立化学验证与工程入口需要补齐

- GAFF 参数分配对照和 J105 使用 Gasteiger 电荷；RadonPy 论文的物性流程使用量化/RESP 电荷。这两项证据不能互相替代。当前已接入若干 QM 电荷方法，但 recipe 未提供直接接口中全部 `charge_options`，也未建立适用于大体系的接点/端基电荷转移验证流程。
- J104 对七个库内模型分子的类型/电荷进行了核对，额外验证了原子重编号下的能量/力一致性。这是良好的回归基础；重编号一致性不是独立的参数物理准确性证明，不能覆盖全部新增聚合物环境。
- `capabilities baseline` 仍汇总历史原始库基准，尚未统一呈现 J99/J104 profile 与 J105 的不同层次结果。需要按具体库、profile、结构和证据等级显示能力。
- 仓库未见 `.github` 内的 CI 配置。可选后端缺失时部分测试跳过，需要一个固定依赖环境的关键链路 CI；这不等于断言项目不存在任何外部 CI。
- 当前 recipe 运行环境主要绑定 LAMMPS/PACKMOL 可执行文件和参数源，建议补全 ISLAND 提交、Python/RDKit/RadonPy/EMC 版本与可执行文件身份。GAFF 安装仍需要文档中的额外依赖操作。
- 模拟调用按单进程启动 LAMMPS，并设置 `OMP_NUM_THREADS=1`；可独立复跑导出的输入，但公共 recipe 需要可配置的 MPI/GPU/调度器执行方式和大规模性能基准。不能把批量并行多个小体系等同于单体系并行扩展。

## 4. “覆盖更多原子类型”应该怎样衡量

原子类型数并非首要指标。同一个 N 在胺、酰胺、芳杂环和离子环境中需要不同处理；新增一个原子类型，也不能自动补全其所有电荷、LJ、键角、扭转和 improper。PCFF 还需成套 Class-II 交叉项。新增接点必须检查所有跨接点相互作用。

以下是对既有 982 条重复单元面板按“是否含某元素”重新分组的结果，**不是完整图或 MD 覆盖率**，各行可重叠：

| 输入分组 | 输入数 | PCFF 扩展分配成功 | OPLS 扩展分配成功 |
|---|---:|---:|---:|
| 全部 | 982 | 899 | 406 |
| 仅 C/H/O/N | 723 | 684 | 366 |
| 含 N | 383 | 335 | 15 |
| 含 F | 134 | 118 | 4 |
| 含 Cl | 41 | 29 | 26 |
| 含 S | 77 | 65 | 10 |
| 含 P | 16 | 1 | 0 |
| 含 Br | 16 | 15 | 0 |

这组数据没有 Si、B 或金属输入。含 N 的 OPLS 数字也受上面的入口差异影响，不能解释为“只支持 15 种含氮聚合物”。[元素统计](evidence/audit_20261125/element-coverage.json)

J104 的 576 条失败被分为分型规则 413、电荷增量 83、扭转 71、角 5、总电荷检查 4。这是每条输入按优先级归入一类的诊断统计；一个输入可能同时缺多项。先统一完整图路径，再重新归因。

建议以后固定报告五层结果：

1. **结构正确**：图、端基、手性、电荷态和拓扑满足请求。
2. **分配完整**：全部相互作用可追溯；明确严格匹配与任何近似。
3. **数值正确**：已知参考构型的能量/力、重排/周期不变性、必要的数值差分检查。
4. **动力学可运行**：明确规模、时长和数值设置，保留失败样品。
5. **采样及性质可信**：收敛、尺寸与种子敏感性，以及适用的独立/实验参考。

优先扩展常用有机化学和跨单元接点，再分批扩展含氟/卤素、含硫、含磷、硅氧烷和离子聚合物。金属配位、无机填料与反应型势另设模型域。具体顺序应由完整图重测的缺项频率和目标用户材料决定，不应预先保证某个任意百分比。

## 5. 相关工作的可借鉴之处

| 工作与主要来源 | 与目标有关的实际设计 | ISLAND 应借鉴什么；边界在哪里 |
|---|---|---|
| [RadonPy](https://doi.org/10.1038/s41524-022-00906-4) | 从重复单元到无定形体相与性质；论文有量化/RESP 电荷、压缩/减压、至少数 ns 的后续平衡及自动判据 | 借鉴成熟平衡与电荷协议。ISLAND 对接其 GAFF 分配，不等于已经复现其完整物性流程。论文 1,070 个成功聚合物与仓库 1,077 条参数对照记录是不同分母 |
| [PolyJarvis v3](https://arxiv.org/html/2604.02537v3) | EMC/LAMMPS 主流程；完整构建试探；压实、退火、熔体和目标温度下的收敛门槛；7 种无定形均聚物、每种 3 副本 | 采用确定性阶段控制与失败恢复。论文报告 13/19 个物性对照达标，未证明任意共聚物、网络或离子体系的通用性 |
| [polyply](https://doi.org/10.1038/s41467-021-27627-4) | 基于已有构建块/参数模板，多尺度随机行走生成复杂拓扑与坐标，支持不同分辨率和力场 | 最适合借鉴长链、支化、嵌段与大体系初始化。参数模板存在是前提，它不是凭任意 SMILES 自动补齐未知参数 |
| [HTPolyNet](https://github.com/cameronabrams/htpolynet)；[论文](https://doi.org/10.1016/j.softx.2022.101303) | 输入单体、聚合反应和配比，生成交联网络；当前维护版使用 GAFF、AmberTools、GROMACS | 借鉴通用单体/反应配置和模板化参数更新。适合作为 GAFF 交联路线参照，不能直接代替 PCFF/OPLS 参数库 |
| [LUNAR](https://github.com/CMMRLab/LUNAR)；[论文](https://doi.org/10.1021/acs.jcim.4c00730) | 原子分型、all2lmp、反应模板及映射、网络分析；读取到的 README 版本为 17November2026 | 用作类型、反应映射及 LAMMPS 导出的独立核对。其示例与规则仍有适用域，不能将“工具存在”视作所有参数已经可靠 |

| [Foyer](https://github.com/mosdef-hub/foyer) | 声明式 SMARTS 原子分型与规则体系；随包提供 OPLS-AA/TraPPE 的子集 | 借鉴规则冲突、优先级和回归验证；其 OPLS 子集不能当作全面 OPLS 覆盖的保证 |

## 6. 建议的阶段与验收条件

以下是后续建议，不表示已实现。

| 阶段 | 主要交付 | 必须验收的结果 |
|---|---|---|
| **J106：统一最终图与输入语义** | 修复默认封端、手性/E/Z；给字符串、完整图、recipe 统一结构契约；明确端基、电荷态和连接点 | 本次 PP/EZ 反例转为正确成功；有效结构跨入口图等价；应拒绝的结构仍明确拒绝；已有案例不退化 |
| **J107：按完整图扩展力场覆盖** | 对 982 条数据做成对重测，加入 Si/P/S/卤素/离子与多端基；预检、缺项定位、来源绑定缓存 | 分母完整；按结构/化学环境解释每个失败；模型化合物与接点的独立类型、电荷和能量/力检查；分配与 MD 分开统计 |
| **J108：通用网络与 GAFF 接入** | 单体/反应模板注册，周期图参数化，接入一种 GAFF/GAFF2 环氧网络，再扩第二类反应 | 单步质量/电荷/价态守恒、跨接点项完整、有限参考整图对照、周期平移不变性、固化及续跑验证 |
