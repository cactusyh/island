# Study protocol

This software-methods study evaluates provenance, identity preservation,
deterministic graph transformations, force-field assignment diagnostics,
periodic backend behavior, checkpoint recovery and trajectory post-processing.
Representative systems are selected only when the declared source covers every
required term. Each result records the graph, packing, source, charge, workflow,
mapping and trajectory hashes.

The primary evidence classes are software contracts, independent numerical
verification and physical validation. Short Reference-platform fixtures support
the first two classes. Physical gates require per-frame box volumes, stable
thermodynamic observables, density block convergence, topology preservation and
replica agreement. The readiness flags remain conservative until those gates
are independently satisfied.
