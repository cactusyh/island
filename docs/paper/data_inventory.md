# Data inventory

The repository contains J17-J23 software fixtures, retained receipts and short
OpenMM Reference workflow records. It does not contain a committed external
cohort of production trajectories with linked stable atom maps and experimental
measurements. The machine-readable inventory records this as a blocked data
gate.

The supplied `radonpy.pdf` is retained as an uncommitted methodological
reference. It is not used as a source of ISLAND data or claims. Synthetic and
software fixtures remain labelled as such.
